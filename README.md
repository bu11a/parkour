# Мастер паркура 2D — онлайн-версия

2D-паркур в браузере с сервером: регистрация и вход по никнейму, смена ника, рекорды на сервере и таблица лидеров по каждой трассе.

## Запуск

Нужен Node.js 18 или новее. Внешних библиотек нет, `npm install` не нужен.

```
node server.js
```

Открой в браузере http://localhost:3000.
Порт можно сменить: `PORT=8080 node server.js` (в Windows PowerShell: `$env:PORT=8080; node server.js`).

## Структура

```
server.js          сервер: API + раздача игры
package.json
public/
  index.html       разметка: игра, вход/регистрация, меню
  style.css        стили
  game.js          игра и работа с API
data/db.json       база (создаётся сама при первом запуске)
```

## API

| Метод | Путь | Что делает |
|---|---|---|
| GET  | /api/me | текущий игрок или `null` |
| POST | /api/register | `{nick, password}` — регистрация и вход |
| POST | /api/login | `{nick, password}` — вход |
| POST | /api/logout | выход |
| POST | /api/nick | `{nick}` — сменить никнейм |
| POST | /api/score | `{level, time}` — сохранить результат (лучший остаётся) |
| GET  | /api/leaderboard?level=N | топ-10 трассы и твоё место |

Правила: ник — 3–16 символов (буквы, цифры, `_`, `-`), без учёта регистра уникален; пароль — от 6 символов.

## Безопасность

- Пароли хранятся только как хэш scrypt с солью.
- Сессия — случайный токен в cookie `HttpOnly; SameSite=Lax`, на сервере хранится только его SHA-256, срок 30 дней.
- POST-запросы принимают только JSON — это защищает от подделки запросов с чужих сайтов.
- Ограничение: 20 попыток входа/регистрации за 10 минут с одного IP.
- При работе через HTTPS запускай с `COOKIE_SECURE=1`.

## Что учесть перед публикацией в интернете

- Результаты присылает браузер, поэтому их можно подделать. Для честной таблицы нужна проверка на сервере (например, запись нажатий и повтор забега).
- JSON-файл подходит для небольшого числа игроков. Для большого — перейди на SQLite/PostgreSQL.
- Ставь сервер за HTTPS (nginx, Caddy) и делай резервные копии `data/db.json`.

Если открыть `public/index.html` без сервера, игра работает в режиме гостя: рекорды хранятся только в браузере.
